= 기억 사진 업로드 API

== 기억 사진 업로드

작성자가 자신의 기억의 방에 담긴 기억 한 건에 사진을 업로드한다. 기존 사진이 있으면 교체된다 (1장 제한). 작성자가 아니면 403을 반환한다.

`multipart/form-data` 의 `photo` 파트로 사진 파일을 전송한다. 응답의 `photoUrl` 은 `/files/` 로 시작하는 서빙 URL 이며, `thumbnailUrl` 은 썸네일이 없으면 null 이다.
