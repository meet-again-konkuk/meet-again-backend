= 인연 충전 API

회원이 인연 상품을 구매하여 자신의 인연 잔액을 적립한다.

== 기본 동작 (할인 없는 상품)

`orderPointPrice`는 클라이언트가 화면에서 본 최종 결제 예상 금액이다. 서버가 재계산한 상품 가격과 불일치하면 충전이 거부된다.
`idempotencyKey`는 클라이언트가 생성한 UUID로, 동일 키의 재요청은 409로 거부되어 중복 결제를 방지한다.
