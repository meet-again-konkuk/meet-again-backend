= 이메일 찾기 API 문서

== 이메일 찾기

이름과 휴대폰 번호로 가입된 회원의 이메일(아이디)을 조회합니다. 조회에 성공하면 마스킹되지 않은 전체 이메일을 반환합니다.

이 API는 SMS 인증 완료가 선행되어야 합니다. `POST /api/sms/verification-code`로 인증번호를 발급받고 `POST /api/sms/verification-code/confirm`으로 인증을 완료한 뒤 호출해야 하며,
휴대폰 번호 인증이 완료되지 않은 상태로 호출하면 `400 (INVALID_INPUT_VALUE)`을 반환합니다.
