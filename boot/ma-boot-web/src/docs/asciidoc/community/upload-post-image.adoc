= 커뮤니티 게시글 이미지 업로드 API

== 게시글 이미지 업로드

본인이 작성한 커뮤니티 게시글에 이미지를 업로드합니다. 게시글당 이미지는 1장만 유지되며, 기존 이미지가 있으면 새 이미지로 교체됩니다.

`multipart/form-data` 의 `image` 파트로 이미지 파일(jpg, jpeg, png, svg, webp / 최대 10MB)을 전송합니다.

최초 업로드 시 `201 Created`, 기존 이미지가 있어 교체된 경우 `200 OK` 로 응답합니다. 응답의 `imageUrl` 은 `/files/` 로 시작하는 서빙 URL 이며, `thumbnailUrl` 은 썸네일이 없으면 null 입니다.

지원하지 않는 확장자를 전송하면 400, 작성자가 아니면 403, 게시글이 없으면 404 를 반환합니다.
