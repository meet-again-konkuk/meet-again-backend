requirement-planner 에이전트를 사용하여 다음 기능의 구현 계획을 작성해줘:

$ARGUMENTS

계획 작성 전에 반드시:
1. requirement-planning 스킬을 참조하여 Design 문서 수준의 상세한 계획을 작성할 것
2. clean-code 스킬을 참조하여 네이밍, 함수 설계, 에러 핸들링 원칙을 반영할 것
3. code-implementation-rules 스킬을 참조하여 OOP 원칙(도메인 행위 부여, 원시값 포장, 일급 컬렉션, 포트 규칙)을 반영할 것
4. 관련 기존 코드를 읽고 프로젝트 패턴을 파악할 것
5. 완료된 계획은 requirement/ 디렉토리에 파일로 저장할 것
