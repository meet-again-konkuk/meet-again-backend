## 프론트 전달 사항 (구현 요청)

### 1. 탈퇴 신청 회원 로그인 시 복구(탈퇴 취소) 안내 UX

- **트리거**: `POST /api/auth/login` 또는 `POST /api/auth/refresh-token` 응답이 **409 Conflict**, ErrorCode `WITHDRAWAL_PENDING`.
  - 의미: "탈퇴 신청(유예 중) 상태라 로그인/토큰갱신이 차단됨".
- **요구 동작**: 사용자에게 *"탈퇴가 진행 중입니다. 탈퇴를 취소하고 계정을 복구하시겠어요?"* 확인.
  - **예** → `POST /api/members/withdrawal/cancellation` (바디 `{ "email", "password" }`) 호출 → **204 No Content** = 복구 완료 → 이어서 로그인 API 재시도.
  - **아니오** → 로그인 중단.
- **참고**:
  - 복구 엔드포인트는 **비인증(public)** 이며 email+password로 본인 확인.
  - 복구 API는 **토큰을 발급하지 않음** → 복구 후 반드시 로그인 API를 다시 호출해야 토큰 획득.
  - 유예 기간(7일)이 지났어도 **데이터 삭제(배치) 전이면 복구 가능**. 이미 삭제됐으면 cancellation도 실패하므로 일반 로그인 실패와 동일하게 처리.
